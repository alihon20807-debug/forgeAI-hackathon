# ClaimGuard (ForgeAI Hackathon)

A Python/FastAPI code-mixed Hinglish/Tanglish voice agent for roadside insurance claims with an integrated safety layer. This project includes cancellable dispatches, anti-sycophancy policy locks, and PII scrubbing, evaluated before and after with Block Convey's PRISM evaluation tool. This is a work in progress.

## Repository layout

- **`research/`** — PRISM evaluation methodology and Indic domain research (in progress)
- **`app/`** — FastAPI backend and voice agent implementation (planned)
- **`evals/`** — PRISM evaluation suite and test harness (planned)
- **`frontend/`** — Web/mobile interface for claim submission (planned)

## Setup

Copy `.env.example` to `.env` and fill in your API keys. See `.env.example` for required environment variables.
